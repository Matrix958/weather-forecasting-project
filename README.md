# Weather Forecasting using Deep Learning

This project predicts temperature, wind speed, and precipitation for the next 7 days using deep learning models like TCN(Temporary Convolutional Network).
## Models Used
- Temporal Convolutional Network (TCN) – R² ≈ 0.96+

## Dataset
- Source: Global Weather Repository
- Data from multiple countries (one weather station per country)

## Folder Structure
- `/notebooks`: Jupyter Notebooks with outputs
- `/data`: Sample dataset
- `/images`: Optional saved plots
- `requirements.txt`: Python dependencies
